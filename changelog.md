# Changelog – Paws of Hope Animal Rescue

This document records the website improvements and updates made during Part 3 of the WEDE5020 Portfolio of Evidence.

## Version 1.0 – Part 2

The original website included:

- Home page.
- About page.
- Services page.
- Enquiry page.
- Contact page.
- Basic HTML forms.
- CSS styling and responsive layouts.
- Website images and navigation.

## Version 2.0 – Part 3

### HTML Improvements

- Updated page titles and meta descriptions.
- Added SEO-related keywords.
- Improved HTML formatting and structure.
- Connected the external JavaScript file to all five HTML pages.
- Added animal search, filter and sorting controls.
- Improved enquiry and contact form structure.
- Added expandable adoption information sections.

- Updated homepage, About Us and Enquiry page images to improve sizing, prevent unwanted cropping and support responsive display.


### CSS Improvements

- Improved image sizing across website pages.
- Added styling for animal listing cards.
- Styled animal search and filter controls.
- Improved form layouts and feedback messages.
- Added hover effects to animal cards.
- Improved tablet and mobile responsiveness.
- Maintained the original cream-and-brown colour scheme.

### JavaScript Improvements

- Added sample animal listing data.
- Implemented animal search functionality.
- Added filtering by dogs and cats.
- Implemented alphabetical sorting.
- Added dynamic animal listing counts.
- Added enquiry form validation.
- Added contact form validation.
- Added feedback messages for form submissions.

### Documentation and Demonstrations

- Created an updated README.md.
- Created this CHANGELOG.md.
- Prepared desktop homepage demonstration.
- Prepared mobile homepage demonstration.
- Documented the website's features and testing requirements.

## Notes

Animal listings are demonstration examples and do not represent confirmed animals available for adoption.

The enquiry and contact forms use client-side JavaScript validation. They do not send information to a backend or email service.
